# VACV SI: модель по структуре молекулы

Воспроизводимое обучение на данных организаторов: SMILES → Morgan fingerprints → прогноз `SI VACV`.
Официальная метрика — **MSE в исходной шкале SI**. Внешние медицинские данные не используются.

Приватный репозиторий: [nisheta19/nuclearIT](https://github.com/nisheta19/nuclearIT).
Для клонирования нужен доступ к репозиторию:

```powershell
git clone https://github.com/nisheta19/nuclearIT.git
cd nuclearIT
```

В репозитории сохранены код, исходные данные организаторов, модели и результаты завершённых
экспериментов. Окружение Python устанавливается отдельно по инструкции ниже. Git сохраняет
исходные байты файлов, чтобы контрольные суммы данных и артефактов не менялись при клонировании.

Текущая модель: **двухэтапная регрессия, Morgan r3, alpha=1, C=0.1**. Внутренний подбор
сравнивал 27 ансамблей разных представлений и 18 двухэтапных вариантов. Выпуск прошёл
все четыре заранее заданных сравнения с процедурой v3:

| Разбиения | Группы | v3 MSE | v4 MSE | Снижение |
|---|---|---:|---:|---:|
| Прежние | Структуры | 15 578 163,577 | 14 816 985,027 | 4,89% |
| Прежние | Каркасы | 19 638 230,023 | 18 713 792,961 | 4,71% |
| Дополнительные | Структуры | 15 449 521,509 | 14 421 766,978 | 6,65% |
| Дополнительные | Каркасы | 17 924 489,793 | 17 010 830,457 | 5,10% |

Двухэтапный вариант оценивает вероятность SI >= 10000 и две условные регрессии, затем
объединяет их прогнозы. Это статистическая гипотеза; смысл метки 10000 не объявляется
установленным. Истинные классы и метки используются только при обучении. Внешние оценки
описывают всю процедуру подбора; финальные параметры выбраны на всём train той же процедурой.
Ансамбли и двухэтапное семейство отдельно оценены как диагностика, а не выбраны по внешним оценкам.

Добавлены 5000 парных bootstrap-пересэмплирований целых групп. Повторные ошибки одной
строки по seed сначала усредняются. Для прежней каркасной проверки интервал изменения
MSE включает ноль: устойчивое преимущество на ней не установлено. Эти интервалы условны
на сохранённых прогнозах, не учитывают всё обучение/подбор и не заменяют независимый тест.
В интерфейсе показаны MSE, MAE, интервалы и сравнение по диапазонам SI.

### Список молекул

В приложении откройте «Список молекул». CSV должен быть в UTF-8, содержать столбец `SMILES`
и необязательный `index`; поддерживаются запятая, точка с запятой и табуляция. До 2 МБ,
2000 строк и 2000 символов в одном SMILES. Другие столбцы, включая CC50/IC50, игнорируются.
Порядок, повторяющиеся и ведущие нули идентификаторов сохраняются в текстовых полях CSV.
Excel может интерпретировать числовые идентификаторы при открытии; импортируйте index как текст.

У неразбираемого SMILES нет прогнозного числа: возвращаются статус и причина. Валидные
строки получают SI, сходство с train, число совпадений структуры, имя/версию и SHA-256 модели.
Есть фильтры и постраничный просмотр, выгрузка включает все строки. Границы сходства
0,3/0,5 описывают покрытие, а не вероятность правильности. Потенциальные формулы в текстовых
полях выгрузки экранируются апострофом. Загруженные CSV не сохраняются и не пополняют train.
CLI соревнования сохраняет прежний явно отмеченный fallback для invalid test; интерактивный
пакетный режим выводит ошибку строки без подстановки среднего.

## Проверки кода

```powershell
New-Item -ItemType Directory -Force .pytest-work | Out-Null
.venv\Scripts\python.exe -X utf8 -m pytest -q --basetemp .pytest-work/local-tests
```

`--basetemp` — выделенный временный каталог тестов: pytest очищает его при следующем запуске.
Не указывайте там каталог с нужными файлами. Локальный каталог используется, потому что системный Temp на этой машине отказал pytest в доступе.

Тесты проверяют группировку одинаковых структур, воспроизводимость, обратное преобразование log1p,
отсутствие концентраций в модельном входе, неизменность меток, игнорирование значений sample,
контроль версии данных, fallback неразбираемых test SMILES, формат submission и повторную загрузку модели.
Синтетические примеры находятся только в тестах и никогда не добавляются к данным соревнования.
Новые тесты проверяют изоляцию внутренних/внешних фолдов, обучение scaler только на train,
хеши входов, загрузку модели в локальном приложении и ограничения HTTP-маршрутов.

## Модели и оценка первого этапа

- Среднее обучающей части фолда — константный baseline для MSE.
- Ridge: `alpha=10`, на SI и на `log1p(SI)`.
- Extra Trees: 400 деревьев, `min_samples_leaf=2`, на SI и на `log1p(SI)`.
- Morgan: radius 2, 2048 бит, `includeChirality=True`. Признаки только из SMILES.
- Три GroupKFold по каноническим структурам, seed 42/137/2026; отдельно проверка по каркасам.
- До пяти фолдов; одинаковые структуры целиком входят в один фолд. Фолды сохраняются до обучения.
- Все MSE считаются в исходной шкале. Log-прогнозы проходят `expm1`.
- Предсказания ограничены снизу нулём, без верхней обрезки. MSE до ограничения тоже сохраняется.

Победитель выбирается по среднему MSE трёх разбиений по структурам; каркасы дают дополнительную диагностику.
OOF используется для выбора модели и поэтому не является независимым тестом итоговой системы.
Широкого подбора параметров, обучения на тестовых ответах и переноса меток по совпадениям нет.

CC50, IC50, их отношения/преобразования/индикаторы пропусков, индекс, название, источник,
метаданные и флаги проверки не являются признаками. В загрузчике задан белый список колонок.
Значения `sample_submit.csv` никогда не читаются для обучения: нужен только его `index`.

Канонизация сохраняет стереохимию, заряды, изотопы, все фрагменты и форму таутомера;
удаляются только номера atom map. Объединения солей и нейтрализации нет.
Для каркасов используется Bemis–Murcko без стереохимии; все ациклические структуры образуют одну группу.
Неразбираемый train останавливает обучение с диагностикой. Неразбираемый test получает среднее train и явный флаг fallback.
