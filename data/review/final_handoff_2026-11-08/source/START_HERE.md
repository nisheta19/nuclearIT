# Итоговый пакет подготовки данных VACV — 8 ноября 2026

Пакет предназначен для передачи команде хакатона: код подготовки данных, снимки источников, отчёты проверок и таблицы для окончательной проверки. Это итоговый выпуск текущей работы по данным, а не готовая модель или submission.

## Что передаём

- `data/handoff/pairs_reviewed.csv`: пять структур из McGuigan 2013 после автоматической и человеческой проверки источника.
- `data/handoff/exact_approved.csv`: три точные пары IC50/CC50 (8i, 8j, 8m) с рассчитанным SI.
- `data/handoff/external_train_exact.csv`: компактная таблица трёх одобренных внешних строк для модели; признаки разрешено строить только из `SMILES`.
- `data/handoff/bounded_reviewed.csv`: две проверенные пары с ограниченным CC50 (8k, 8l). Не превращать границы в точные цели и не включать в обычную точечную регрессию.
- `data/handoff/validation/`: результат штатного валидатора — 3 `accepted_exact` и 2 `accepted_bound`.
- `data/literature/mcguigan2013.pdf`: источник; схема 1 на PDF-странице 5, таблица 2 на страницах 9–10.
- `docs/19-third-paper-stereochemistry.md`: итог проверки пяти структур и отсутствия пересечений с организаторскими структурами по проверенным ключам.
- Остальные `data/` и `docs/`: архив источников и история проверки. Название `curated` не означает допуск к обучению.

Финальных одобренных внешних обучающих строк: 3. Пользователь вручную подтвердил значения, операторы, колонку BSC-1, соответствия 8i–8m и стереохимические связи на схеме 1. Для 8i, 8j и 8m выставлены `pairing_reviewed=yes` и `approved_for_training=yes`; SI рассчитан только после этой проверки. Строки 8k и 8l имеют статус `accepted_bound`, но `approved_for_training=no` для обычной точечной регрессии.

## Важные выводы

Пять структур McGuigan не совпадают с train/test при точной канонизации и сравнении крупнейшего фрагмента без стереохимии. Таутомерная эквивалентность отдельно не проверялась. Три точные записи сами по себе не гарантируют улучшения модели.

У предыдущей статьи десять структур ChEMBL расходились с переданными авторскими MOL; структуры из MOL уже встречаются в train/test. Их нельзя считать новыми обучающими соединениями. См. `docs/16-author-mol-review.md`.

Модель v4 находится в отдельном проекте nuclearIT и в этот архив не включена. Она работает на версии hakathonMiphi с 81 меткой 10000. Таблица `data/organizer_audit/train_for_model_unreviewed.csv` относится к другой версии с 83 нулями; не подменять ею вход модели. Объяснение специальных меток организаторами не получено. См. `docs/14-model-project-review.md`.

## Запуск

Распаковать ZIP и выполнять команды из его корня. Python 3.10+; проверка CSV и тесты не требуют химических зависимостей.

```sh
python -m unittest discover -s tests -v
python medical_data.py validate data/handoff/pairs_reviewed.csv data/handoff/validation
```

Для воспроизведения химической проверки установить версии из `requirements-chemistry.txt`:

```sh
python -m pip install -r requirements-chemistry.txt
python review_author_mols.py data/literature/second-paper-author-mol.zip
python review_third_paper_stereo.py
python package_handoff.py
```

В архив не включены локальные зависимости, Git, кэши и временные картинки. `MANIFEST_SHA256.json` содержит контрольные суммы всех остальных файлов. Исходные JSON и документы сохранены для аудита; некоторые старые скрипты требуют исходные пути/аргументы, указанные в соответствующих отчётах.

## Поля финальных таблиц

`record_id` — уникальная запись; `compound_source_id` — номер в статье; `smiles` — проверяемая структура ChEMBL; `doi`, `source_*` — происхождение; `activity_*` — IC50, единица и оператор; `cc50_*` — цитотоксичность, единица и оператор; `pairing_evidence` — основание сопоставления; `pairing_reviewed` — человеческая проверка; `approved_for_training` — допуск; `review_status` — текущий статус; `overlap_checked` — выполненный поиск пересечений. Концентрации не использовать как признаки модели.
