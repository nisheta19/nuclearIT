# Контракт соревнования

Источник: правила, предоставленные пользователем 7 ноября 2026 года, и sample_submit.csv. Они уточняют первоначальное ТЗ.

- Метрика MSE = mean((SI_true - SI_predicted)^2), в исходной шкале SI. При преобразовании цели для обучения перед submission нужно выполнить обратное преобразование.
- CSV содержит ровно index,SI VACV в таком порядке. Индексы и порядок строк сверяются с sample.
- Значения sample не являются истинными ответами и не используются как обучающие метки.
- CC50_uM и IC50_uM_VACV запрещены как признаки для построения модели и предсказания. Запрет распространяем на их отношения, логарифмы и прочие производные, раскрывающие цель.
- Концентрации сохраняем в медицинском архиве для проверки меток. Не вычисляем по ним ответы для test.
- Для модели готовим отдельную таблицу с идентификатором, SMILES и целевым SI для обучения; для test — идентификатор и SMILES. Признаки рассчитываются из структуры. DOI и экспериментальные метаданные остаются в архиве для аудита и анализа групп при валидации.
- Большие ошибки имеют квадратичный вклад в MSE. Проверяем единицы и подозрительные метки; не удаляем высокие SI только из-за величины.
- Требуется сбор открытых данных. Дополнительные ограничения на внешние данные, если они есть, пока не предоставлены.

Исходные train.csv и test.csv пока отсутствуют в проекте. Не подтверждены названия столбцов, пропуски, распределение цели и пересечения структур. Число строк sample само по себе не подтверждает число строк test.
