# v8: результат после Kaggle score 10 913 537,18910

Итоговый файл: **`artifacts/stable-v8/submission.csv`**, 597 строк, столбцы
`index,SI VACV`. SHA-256:
`827916dabf56f2924fe98a09577d9456a35c70410e44d8fcfb9c0138401db677`.
Это новая модель; прежний `artifacts/augmented-v5/submission.csv` сохранён.

Сообщённый пользователем score относится к прежнему v5. Для MSE это RMSE
**3303,56 SI**. Само число не определяет место: leaderboard из доступной сессии
не открылся, статус public/private неизвестен. Новый CSV автоматически на Kaggle
не отправлялся. Перенос процента локального улучшения на Kaggle не обоснован.

## Что изменилось

Вместо одного Morgan r3 используется среднее двух двухэтапных моделей: Morgan
r2 и r3, по 2048 бит, с сохранением хиральности. Веса фиксированы: 0,5 и 0,5.
У каждой модели классификатор оценивает вероятность SI ≥ 10000, а две
Tanimoto-регрессии предсказывают условные средние SI. Параметры фиксированы:
`C=0.1`, `alpha=1`. Они взяты из параметров ранее выпущенной модели.
Порог 10000 — статистическая часть модели, медицинский смысл метки не установлен.

Рабочая модель обучена на прежних **320 строках**. Внешние записи не добавлены.
Все метки, в том числе 2 нуля, 81 значение 10000 и выброс 36066,667, сохранены.
CC50, IC50, их производные, пропуски, индексы и источники не используются как признаки.
Метрика остаётся MSE в исходной шкале SI.

## Результаты

Сравнение с процедурой v4/v5, которая сформировала ранее отправленный CSV:

| Серия | Группировка | MSE v4/v5 | MSE v8 | Снижение |
|---|---|---:|---:|---:|
| Прежняя | Структуры | 14 816 985,027 | 14 262 906,092 | 3,74% |
| Прежняя | Каркасы | 18 713 792,961 | 18 284 534,908 | 2,29% |
| Дополнительная | Структуры | 14 421 766,978 | 14 086 798,335 | 2,32% |
| Дополнительная | Каркасы | 17 010 830,457 | 16 963 591,735 | 0,28% |
| Новые seed | Структуры | 13 646 313,014 | 13 622 860,063 | 0,17% |
| Новые seed | Каркасы | 17 113 240,404 | 16 904 444,287 | 1,22% |

Всего 65 внешних фолдов: прежние 45 и ещё 20 на seed 24117 и 89101 для обеих
группировок. Совпадающие структуры и каркасы не разделяются между обучением
и проверкой в соответствующей схеме. Все шесть заранее заданных условий
снижения MSE выполнены.

**Ограничение оценки:** вариант v8 выбран после исследовательского сравнения
четырёх вариантов на прежних 45 фолдах. Поэтому эти цифры — оценки разработки,
а не непредвзятая оценка вложенного выбора v8. Для фиксированной модели v8
внутренние оценки сохраняются как диагностика; подбора по ним нет. Новые seed
используют те же молекулы и проверяют устойчивость к разбиению, но не заменяют
независимый набор. Более низкий Kaggle score не гарантирован.

Три из четырёх условных 95% bootstrap-интервалов снижения MSE на прежних сериях
включают ноль. Оба интервала на новых seed тоже включают ноль. Убедительное
преимущество по каркасам этими данными не установлено. Кроме того, MAE по
структурам на дополнительной серии вырос с 2414,23 до 2450,20: модель выбиралась
по MSE, улучшение не распространяется на все метрики.

## Какие варианты не стали итоговыми

- **v6:** 140 вариантов представления/модели и смеси с прежней моделью. Проверка
  по каркасам ухудшилась; версия отклонена, её `submission.csv` совпадает с v5.
- **v7:** шесть вариантов двухэтапных ансамблей с внутренним подбором. По
  структурам улучшение, но дополнительная серия каркасов ухудшилась на 0,83%,
  а обе новые серии тоже ухудшились. Версия отклонена.
- В исследовательской проверке v8 сравнивались фиксированное усреднение,
  отпечатки шириной 8192 бита и два порога фильтрации редких битов. Увеличение
  ширины и фильтрация не превзошли простое фиксированное усреднение по всем
  сериям. Полные результаты сохранены в
  `artifacts/stable-v8-review/development_probe/`, включая код, план и OOF.

## Проверки и воспроизведение

- 83 теста прошли. Отдельно проверены усреднение компонентов, сериализация,
  совпадение кэшированных и обычных расчётов, разделение структур и каркасов.
- Независимый проверяющий скрипт подтвердил хеши 74 артефактов v8, 65 внешних
  фолдов, 390 внутренних проверок групп, неизменность исходных меток и
  воспроизведение обоих CSV загруженными моделями.
- Через HTTP API проверены все 597 строк test, совпадение выгрузки CSV и
  одиночного прогноза, а также пакет из 2000 строк. Запущенное приложение
  использует v8. Подтверждение: `artifacts/stable-v8-review/batch_api_verification.json`.
- Набор данных закреплён хешами. Оценки другой версии train с 83 нулями сюда
  не подмешиваются. Значения 10000 по-прежнему требуют ответа организаторов.
- Исправлен сбой HTTP на Windows: отклонённый небольшой POST-запрос больше
  не оставляет непрочитанное тело перед закрытием соединения. Ограничения
  локального доступа, размера и времени чтения сохранены.

```powershell
.venv\Scripts\python.exe -X utf8 scripts/run_stable_ensemble.py --config configs/stable_fixed.json --output artifacts/new-fixed-run
.venv\Scripts\python.exe -X utf8 scripts/verify_similarity_run.py --run artifacts/stable-v8 --output artifacts/stable-v8-review/verification.json
.venv\Scripts\python.exe -X utf8 -m vacv.server --run artifacts/stable-v8 --port 8765
```

Для новых seed воспроизводящая команда использует закреплённые результаты
прежней процедуры из `artifacts/similarity-v6`; экспериментальная модель v6
не участвует в прогнозах v8. В `source_snapshot` сохранены код расчёта и скрипт.
