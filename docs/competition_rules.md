# Текущие рабочие правила

Основание — прямое поручение пользователя 7 ноября 2026 года и последующее уточнение источника данных.

1. Метрика — MSE в исходной шкале `SI VACV`.
2. Текущий источник — оригинальный `hakathonMiphi.zip`, явно выбранный пользователем после уточнения различий версий.
3. Официальные метки не исправлять автоматически и не удалять по величине. Нули и 10000 сохранять.
4. Признаки только из SMILES. CC50, IC50 и их производные, включая индикаторы пропусков, запрещены.
5. Одинаковые канонические структуры удерживать в одной группе при валидации.
6. Внешние данные не добавлять: медицинская проверка не завершена. Файлы внешних наборов не загружаются.
7. Sample задаёт формат и порядок индексов; его значения не являются ответами.
8. Submission содержит `index,SI VACV`, 597 строк в порядке test/sample. Проверка формата не проверяет качество.

Остаются неизвестны смысл специальных меток и способ формирования скрытого теста.
Проверки по структурам и каркасам представлены отдельно. Они не являются обещанием результата на Kaggle.

Это инженерный прототип для соревнования, не клиническая интерпретация данных.
