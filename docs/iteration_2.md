# Второй этап, 7 ноября 2026

Пользователь поручил реализовать ранее предложенные улучшения. Источник остался hakathonMiphi;
новый train с 83 нулями не поступил. Подмена целей не выполнялась, внешние данные не подключались.

## Что завершено

- SHA-256 train/test/sample теперь проверяется до чтения модельного входа, а не только записывается в отчёт.
- Добавлен вложенный GroupKFold: 20 внешних фолдов; внутри каждого 3 фолда и 20 фиксированных кандидатов.
- Проверены radius 2/3, binary/count fingerprints и 11 молекулярных дескрипторов.
- Все fitted-преобразования обучаются внутри соответствующего обучающего фолда.
- Сохранены внутренняя принадлежность строк, результаты кандидатов, внешний выбор и итоговые OOF.
- Разобраны дубликаты, экстремальная метка, соседи только из обучения своего фолда, ошибка по диапазонам SI и сходства.
- Добавлены экспортируемые научные графики, локальное приложение с реальным инференсом, тесты API и браузера.
- Текст отчёта baseline теперь берёт версию, размеры, число seed и параметры из конфигурации.

## Результат

Полная процедура поиска: MSE структуры 15 712 070,913 (на 1,67% ниже baseline),
MSE каркасы 20 311 096,534 (на 0,22% выше baseline).
Правило выпуска было записано до запуска: улучшение по структурам и отсутствие ухудшения по каркасам.
Условие не выполнено, сохранён прежний Ridge. Новый submission побайтно совпадает с первым.

Лучшее диагностическое представление по структурам — отдельно настроенный Morgan r3,
MSE 15 620 107,845. Оно не назначено победителем после просмотра внешней таблицы:
это был бы новый выбор по уже просмотренной оценке. Возможный дальнейший эксперимент
с отдельной r3-стратегией должен сохранять эту историю выбора и не называться независимым подтверждением.

## Проверки и ограничения

27 тестов прошли. Браузер проверен в Edge на ширинах 1440 и 390 px: пустой, ошибочный и корректный ввод,
рисунок структуры, три соседа, таблица качества, загрузка графиков, отсутствие горизонтального переполнения всей страницы.
Для широкой научной фигуры на телефоне сохранена внутренняя горизонтальная прокрутка.
Встроенный CUA-браузер дважды не ответил; визуальная проверка выполнена Playwright в отдельном локальном Edge.
Один тестовый набор пришлось сделать богаче каркасами: защитная проверка корректно остановила вложенную валидацию,
когда внутри внешнего обучения оставалась только одна группа. Условия проверки на реальных данных не ослаблялись.

Настройки браузерного теста исправлены для работы с CSP без unsafe-eval: ожидания используют locators,
а политика приложения не ослаблялась. Matplotlib выдаёт предупреждения совместимости pyparsing о deprecated API;
это не ошибки построения графиков. Зафиксированы точные версии окружения.

Медицинская верификация первичных меток, новый train и проверенные внешние дополнения остаются зависимостями от команды.
Никаких файлов не публиковали и на Kaggle не отправляли.
