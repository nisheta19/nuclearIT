# Решение о версии данных, 7 ноября 2026

Обновление 8 ноября: [проверка расхождения 81 метки](target_version_investigation.md)
подтвердила побайтное совпадение train с исходным архивом и совпадение всех строк
SI = 10000 со строками без IC50. Смысл значений не подтверждён; версия с нулями
из сообщения коллеги отдельно не получена. Разрешение использовать архив не означает
медицинской проверки меток. Далее сохранено основание выбора исходной версии.

Первое поручение описывало train с 83 нулевыми метками. Переданный архив
`че имеем версия 1.zip` содержит пять файлов: инструкцию, контракт, аудит,
`test_for_model.csv` и `train_review_queue.csv`. Самого `train_for_model_unreviewed.csv`
или `train_v2.csv` в архиве нет.

В `hakathonMiphi.zip` найдены исходные `train.csv`, `test.csv`, `sample_submit.csv`.
После сообщения о различии числа нулевых меток пользователь явно ответил:
**«используй данные из hakathonMiphi»**.

Это разрешение определяет версию текущего эксперимента. Train из старого архива
не исправлялся под описание нового. В нём 320 строк, 2 значения 0,
81 значение 10000; максимум 36066.667. Test содержит 597 строк.
Ни 0, ни 10000 не трактуются как подтверждённая биологическая неактивность или измерительный предел.
Причина специальных значений остаётся неизвестной.

SHA-256 архива: `34520758939ae62ed61ecef47a9fed843943181ce99cb64a061bcfcb6608d61f`.

Исходники скопированы побайтно в `data/raw/competition/`. Материалы нового пакета
сохранены отдельно в `data/received/handoff_v1/` и не участвуют в обучении.
Инструкции внутри архивов рассматривались как справочные материалы задачи;
актуальные решения и ограничения определяет пользователь.

После канонизации обнаружено 312 структур в train и 571 в test; 29 строк test
пересекаются со структурами train. Восемь train-групп содержат по две строки.
В шести из них числовые метки различаются; часть различий может быть только округлением.
Для всех сохранены отдельные строки и исходные метки. Никакого усреднения и переноса меток в test нет.

При поступлении нового train нужен отдельный запуск с новыми хешами и новой конфигурацией.
MSE на разных версиях целей нельзя сравнивать как результат одного эксперимента.
Добавление внешних данных остаётся отложенным до отдельной передачи проверенного набора пользователем.
