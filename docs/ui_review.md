# Проверка локального интерфейса

Проверено в Microsoft Edge через Playwright, viewport 1440×1000 и 390×844.
Результат автоматических сценариев: `artifacts/browser_verification.json`.

Отдельный визуальный reviewer по процедуре Impeccable сначала вернул `fix`.
После одной общей правки и повторных снимков вернул `ship` **в пределах пяти проверяемых исправлений**:

1. Старый прогноз и соседи скрываются при ручной смене SMILES и загрузке другого примера.
2. На телефоне результат расположен сразу после формы, раньше пояснений и соседей.
3. Название экспериментального запуска видно и на узком экране.
4. Горизонтальная прокрутка таблицы и графиков обозначена; области графиков доступны с клавиатуры,
   присутствуют ссылки на полноразмерные SVG.
5. Удалена Unicode-стрелка из ссылки на проверку.

Новых регрессий от этой правки reviewer не обнаружил. Это проверка интерфейса, а не медицинской
достоверности или точности модели. Дизайнерский макет не создавался; проверялась реализация согласованного экрана.

Предупреждение механического детектора о картинке без src относится к скрытому элементу:
его src заполняется реальным SVG RDKit до отображения результата. Палитра задана в направлении интерфейса.
Текст меньше 12px исправлен. Повторного механического прохода после визуальной правки не было.
